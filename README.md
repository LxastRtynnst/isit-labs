# Отчет по лабораторной работе №1

## Задание

**Вариант 7. Система бронирования спортивных площадок**

Система предназначена для бронирования спортивных площадок. Необходимо учитывать площадки, виды спорта, расписание и пользователей. Пользователь должен иметь возможность выбирать площадку и время бронирования, а администратор — управлять площадками и расписанием.

## Проблема и цель

**Проблема:** В настоящее время бронирование спортивных площадок часто осуществляется по телефону или через устные договоренности, что приводит к путанице, двойному бронированию, отсутствию единого расписания и сложностям с контролем загрузки.

**Цель:** Разработать информационную систему для централизованного бронирования спортивных площадок, которая позволит пользователям самостоятельно выбирать площадку и время, а администраторам — управлять расписанием.

**Область применения:** Система предназначена для использования в спортивных комплексах, фитнес-центрах, учебных заведениях для управления бронированием.

## Объекты предметной области

- **Площадка**
  - Вид спорта
  - Расписание
- **Пользователь**
- **Бронирование**
- **Администратор**

![Диаграмма предметной области](images/subject-area.png)

## Роли и пользователи

| Роль | Назначение | Основные действия |
|------|------------|-------------------|
| **Администратор** | Управление площадками и расписанием | Добавление/редактирование площадок, настройка расписания, подтверждение/отмена броней, управление пользователями |
| **Пользователь** | Бронирование площадок | Просмотр доступных площадок, выбор времени, создание брони, отмена брони, просмотр своих броней |
| **Менеджер** | Контроль загрузки и финансов | Просмотр отчетов по бронированиям, управление ценами, работа с клиентами |

## Функциональные требования

Система должна позволять:

- Регистрировать пользователей и входить в систему.
- Просматривать список доступных спортивных площадок.
- Фильтровать площадки по виду спорта.
- Отображать актуальное расписание выбранной площадки.
- Создавать бронирование на выбранное время.
- Проверять отсутствие пересечений с другими бронированиями.
- Отменять своё бронирование.
- Отправлять уведомления о подтверждении бронирования.
- Добавлять, редактировать и удалять площадки (администратор).
- Настраивать расписание работы площадок (администратор).
- Просматривать все бронирования и управлять их статусами (администратор).
- Формировать отчёты по загрузке площадок (менеджер).

## Концепция ИС

Система представляет собой **веб-приложение**, доступное через браузер. Пользователи могут регистрироваться и входить в систему с использованием учетных данных. После входа пользователи видят список доступных площадок и могут бронировать время. Администраторы управляют площадками и расписанием. Менеджеры просматривают отчеты.

**Основные компоненты:**

- Веб-интерфейс для взаимодействия с пользователями.
- Серверная часть для обработки запросов и управления данными.
- База данных для хранения информации о площадках, бронированиях, пользователях и расписании.
- API для взаимодействия между веб-интерфейсом и серверной частью.
